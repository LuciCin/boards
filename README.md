# boards · `archive` branch

**This branch is generated.** A GitHub Action snapshots the live boards into `snapshots/<date>/` — once a week, and only when games have been played since the last snapshot — so a season's history outlives the `live` branch, which only ever shows *now*. Nothing here is edited by hand.

- **The site:** https://lucicin.github.io/boards/
- **Source, README, workflows:** the [`main`](https://github.com/LuciCin/boards) branch
- **How the pipeline and the branches work:** the [wiki](https://github.com/LuciCin/boards/wiki)
- **What's served right now:** the [`live`](https://github.com/LuciCin/boards/tree/live) branch
